# ADR-010: PostgreSQL RLS

Date: 2026-09-30

Status: Selected for architecture baseline

## Context

Privy360 must implement the full MASTER_SPEC platform across four deployment modes with default-deny security and durable traceability. The bid is an early release milestone only.

## Decision

Shared SaaS uses FORCE RLS with transaction-local context, non-owner runtime roles and composite tenant FKs.

## Alternatives and rationale

App filters alone fail on missed predicates; schema-per-tenant complicates fleet migrations without eliminating auth needs.

## Consequences and verification

SQL injection remains separate risk; migrations/bypass roles isolated; pool and negative tests mandatory. Normative details and required tests: [contract](../SECURITY_ARCHITECTURE.md). Applicable approval gates are in [ARCHITECTURE](../ARCHITECTURE.md).

## Revisit trigger

Measured failure to meet security, portability, throughput or regulatory traceability requirements; propose a superseding ADR with migration and compatibility impact before changing this choice.
