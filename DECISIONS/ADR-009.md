# ADR-009: Multi-tenancy

Date: 2026-09-30

Status: Selected for architecture baseline

## Context

Privy360 must implement the full MASTER_SPEC platform across four deployment modes with default-deny security and durable traceability. The bid is an early release milestone only.

## Decision

Tenant is explicit security boundary; hierarchical legal entities/units within tenant; all profiles keep tenant ownership.

## Alternatives and rationale

Tenant-by-host or implicit environment alone allows confused-deputy and migration errors.

## Consequences and verification

Server membership binding, dedicated deployment routing after authentication, quotas. Normative details and required tests: [contract](../DOMAIN_MODEL.md). Applicable approval gates are in [ARCHITECTURE](../ARCHITECTURE.md).

## Revisit trigger

Measured failure to meet security, portability, throughput or regulatory traceability requirements; propose a superseding ADR with migration and compatibility impact before changing this choice.
