# ADR-032: Extensibility without arbitrary code

Date: 2026-09-30

Status: Selected for architecture baseline

## Context

Privy360 must implement the full MASTER_SPEC platform across four deployment modes with default-deny security and durable traceability. The bid is an early release milestone only.

## Decision

Versioned policy AST, templates/custom fields and adapter ports; future discovery, Digital Twin and CI evaluate pinned graph/policy versions.

## Alternatives and rationale

Tenant code/eval and untyped JSON relationships bypass validation and create migration traps.

## Consequences and verification

Schemas/classification/retention required; future capabilities cannot override core security. Normative details and required tests: [contract](../MODULE_BOUNDARIES.md). Applicable approval gates are in [ARCHITECTURE](../ARCHITECTURE.md).

## Revisit trigger

Measured failure to meet security, portability, throughput or regulatory traceability requirements; propose a superseding ADR with migration and compatibility impact before changing this choice.
