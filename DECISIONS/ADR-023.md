# ADR-023: Shared SaaS deployment

Date: 2026-09-30

Status: Selected for architecture baseline

## Context

Privy360 must implement the full MASTER_SPEC platform across four deployment modes with default-deny security and durable traceability. The bid is an early release milestone only.

## Decision

Multi-zone private services with RLS, tenant quotas, per-tenant keys and no default operator content access.

## Alternatives and rationale

A shared database without layered isolation is unacceptable; dedicated-only prevents economical SaaS.

## Consequences and verification

Tenant escape/load tests and operational support grant controls. Normative details and required tests: [contract](../DEPLOYMENT_ARCHITECTURE.md). Applicable approval gates are in [ARCHITECTURE](../ARCHITECTURE.md).

## Revisit trigger

Measured failure to meet security, portability, throughput or regulatory traceability requirements; propose a superseding ADR with migration and compatibility impact before changing this choice.
