# ADR-004: PostgreSQL and SQL-first persistence

Date: 2026-09-30

Status: Selected for architecture baseline

## Context

Privy360 must implement the full MASTER_SPEC platform across four deployment modes with default-deny security and durable traceability. The bid is an early release milestone only.

## Decision

PostgreSQL authoritative store, typed SQL repositories with Kysely adapter, reviewed SQL migrations.

## Alternatives and rationale

Document-only persistence weakens graph/FK integrity; ORM auto-sync risks unreviewed schema drift.

## Consequences and verification

Pin compatible versions in foundation; RLS-aware transaction adapter, expand/contract migrations. Normative details and required tests: [contract](../DATABASE_SPEC.md). Applicable approval gates are in [ARCHITECTURE](../ARCHITECTURE.md).

## Revisit trigger

Measured failure to meet security, portability, throughput or regulatory traceability requirements; propose a superseding ADR with migration and compatibility impact before changing this choice.
