# ADR-001: Modular monolith

Date: 2026-09-30

Status: Selected for architecture baseline

## Context

Privy360 must implement the full MASTER_SPEC platform across four deployment modes with default-deny security and durable traceability. The bid is an early release milestone only.

## Decision

Use explicit domain modules and shared deployment, with separate worker process for async work.

## Alternatives and rationale

Microservices introduce distributed invariants and operational cost before measured need; one unstructured monolith defeats ownership.

## Consequences and verification

Module import rules and contract tests mandatory; extraction requires new ADR. Normative details and required tests: [contract](../ARCHITECTURE.md). Applicable approval gates are in [ARCHITECTURE](../ARCHITECTURE.md).

## Revisit trigger

Measured failure to meet security, portability, throughput or regulatory traceability requirements; propose a superseding ADR with migration and compatibility impact before changing this choice.
