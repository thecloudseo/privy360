# ADR-008: S3-compatible storage

Date: 2026-09-30

Status: Selected for architecture baseline

## Context

Privy360 must implement the full MASTER_SPEC platform across four deployment modes with default-deny security and durable traceability. The bid is an early release milestone only.

## Decision

Portable private versioned object storage behind adapter; MinIO reference for private deployments.

## Alternatives and rationale

Database blobs increase backup/load costs; public object URLs undermine authorization.

## Consequences and verification

Provider contract tests for encryption/versioning/locking; metadata in PostgreSQL. Normative details and required tests: [contract](../DEPLOYMENT_ARCHITECTURE.md). Applicable approval gates are in [ARCHITECTURE](../ARCHITECTURE.md).

## Revisit trigger

Measured failure to meet security, portability, throughput or regulatory traceability requirements; propose a superseding ADR with migration and compatibility impact before changing this choice.
