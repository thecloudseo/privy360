# ADR-021: Connector capability architecture

Date: 2026-09-30

Status: Selected for architecture baseline

## Context

Privy360 must implement the full MASTER_SPEC platform across four deployment modes with default-deny security and durable traceability. The bid is an early release milestone only.

## Decision

Signed versioned adapters in isolated workers with explicit capabilities, secret refs, egress and scoped execution.

## Alternatives and rationale

Arbitrary plugin code in API process and broad credentials widen tenant blast radius.

## Consequences and verification

Destructive adapters need plan approval, hold checks and reconciliation; read-only default. Normative details and required tests: [contract](../MODULE_BOUNDARIES.md). Applicable approval gates are in [ARCHITECTURE](../ARCHITECTURE.md).

## Revisit trigger

Measured failure to meet security, portability, throughput or regulatory traceability requirements; propose a superseding ADR with migration and compatibility impact before changing this choice.
