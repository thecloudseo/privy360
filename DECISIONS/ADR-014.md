# ADR-014: Relational Compliance Evidence Graph

Date: 2026-09-30

Status: Selected for architecture baseline

## Context

Privy360 must implement the full MASTER_SPEC platform across four deployment modes with default-deny security and durable traceability. The bid is an early release milestone only.

## Decision

Typed relational edges and immutable provenance, bounded authorized graph query templates.

## Alternatives and rationale

Generic dangling graph IDs lose FK integrity; separate graph database adds sync/security burden initially.

## Consequences and verification

Reverse indexes, temporal edges and resource-scoped traversal; optional derived graph later. Normative details and required tests: [contract](../DATABASE_SPEC.md). Applicable approval gates are in [ARCHITECTURE](../ARCHITECTURE.md).

## Revisit trigger

Measured failure to meet security, portability, throughput or regulatory traceability requirements; propose a superseding ADR with migration and compatibility impact before changing this choice.
