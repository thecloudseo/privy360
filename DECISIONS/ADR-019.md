# ADR-019: Evidence file lifecycle

Date: 2026-09-30

Status: Selected for architecture baseline

## Context

Privy360 must implement the full MASTER_SPEC platform across four deployment modes with default-deny security and durable traceability. The bid is an early release milestone only.

## Decision

Encrypted immutable quarantine, validate/scan before availability, isolated safe previews and authorized gateway downloads.

## Alternatives and rationale

Immediate public upload delivery and mutable bytes break evidence integrity and execute hostile content.

## Consequences and verification

Scanner outage fails closed; custody/checksum/hold/retention tracked per version. Normative details and required tests: [contract](../WORKFLOW_SPEC.md). Applicable approval gates are in [ARCHITECTURE](../ARCHITECTURE.md).

## Revisit trigger

Measured failure to meet security, portability, throughput or regulatory traceability requirements; propose a superseding ADR with migration and compatibility impact before changing this choice.
