# ADR-035: Static analysis gate when GitHub Advanced Security is unavailable

Date: 2026-10-15

Status: Decided — Option 1 (keep CodeQL required; time-bounded blocked gate). Decided by the repository owner on 2026-10-15; Chief Architect ratification and security risk acceptance still pending. Not a supersession of any Selected ADR.

## Context

The `codeql` job in `.github/workflows/foundation.yml` cannot pass on the private repository `thecloudseo/privy360`. Code scanning returns HTTP 403, and enabling GitHub Advanced Security returns HTTP 422 "not purchased". The account owner has declined to purchase it.

The approved baseline still requires CodeQL:

- `DEPLOYMENT_ARCHITECTURE.md` (every PR gate list) names CodeQL.
- `BUILD_PLAN.md` (acceptance criteria) names CodeQL.
- `MASTER_SPEC.md` (security gates) names CodeQL.
- `tests/security/workflow.test.mjs` asserts a `codeql` job exists and that `assert-sarif-clean` runs.

Removing the job therefore conflicts with approved architecture and with a legitimate security test. AGENTS.md §2 requires escalation for that conflict, and §5 forbids deleting or weakening security tests to obtain a green build. §29 forbids bypassing failing mandatory gates.

Semgrep (`p/security-audit`, `--error`) already runs in CI as a SAST gate. It does not provide CodeQL's data-flow queries or GitHub alert handling.

## Decision

None is made by this ADR. Options for the Chief Architect:

1. **Keep CodeQL required; defer the gate.** Keep the `codeql` job and the test unchanged. Record the job as an explicit, time-bounded blocked gate with an owner, until GHAS is purchased or the repo is made public. Merges proceed only under documented security-owner risk acceptance.
2. **Supersede the CodeQL requirement with Semgrep.** Requires a new ADR that updates `DEPLOYMENT_ARCHITECTURE.md`, `BUILD_PLAN.md`, `MASTER_SPEC.md`, and the security-gate test, plus a documented coverage comparison against CodeQL's `security-and-quality` query set.
3. **Make the repo public** so CodeQL is free. Requires separate review of exposed content, including the regulatory corpus and evidence fixtures, before any change.

### Decision taken: option 1

- The `codeql` job and `tests/security/workflow.test.mjs` stay unchanged. No approved architecture is edited.
- **Gate status: BLOCKED.** Cause: GHAS not purchased for a private repository.
- **Owner:** repository owner (`thecloudseo`).
- **Expiry:** 2026-11-15. Before then, either purchase GHAS or make the repo public (option 3), or the Chief Architect must record a new decision.
- **Interim control:** Semgrep (`p/security-audit --error`) remains a blocking SAST gate. Any merge while `codeql` is red needs a documented, signed security-owner risk acceptance referencing this ADR.

## Consequences

- Option 1: the `quality`/`codeql` pipeline stays red until resolved. Nothing ships through it without the documented risk acceptance above.
- Option 2: CodeQL-specific coverage is lost and must be recorded as residual risk.
- Option 3: no tool change, but a publication decision with its own privacy and security review.

## Verification

- Semgrep pin verified on Python 3.12 with `setuptools==80.9.0` and `semgrep==1.136.0`.
- The `tests/security/workflow.test.mjs` assertions remain unchanged under option 1.

## Revisit trigger

GHAS purchase or public visibility change, or a superseding ADR from the Chief Architect.
