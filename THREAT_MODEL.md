# Threat model and verification register

Scope: full production platform and four deployment profiles. Assets: tenant business data, subject rights, credentials/keys, legal corpus, evidence integrity, consent/audit history, availability and customer trust. Adversaries: anonymous attackers, malicious principals/staff/operators, compromised workloads/suppliers/connectors and hostile documents/model outputs. Trust boundaries are specified in SECURITY_ARCHITECTURE. All listed threats are initially HIGH until controls are implemented/tested; approval of residual risk is human/security-owned, not this document. Prioritize tenant escape, authorization, sensitive-data leakage and irreversible actions before availability conveniences.

| Threat / abuse case | Preventative controls | Detective controls | Recovery controls | Required adversarial verification |
|---|---|---|---|---|
| **Authentication attacks** — Spoof issuer/audience, account linking or recovery to assume staff/principal identity | OIDC validation, PKCE/state/nonce, exact redirects, verified linking and assurance-preserving recovery | IdP anomaly and token validation failure alerts | Revoke sessions, disable compromised identity, reviewed recovery | invalid issuer/audience, nonce/replay and email-linking negatives |
| **Credential stuffing** — Automated password attempts and account enumeration | MFA, per-IP/account progressive limits, generic errors, breached credential policy at IdP | Failure-rate and distributed attack signals | Block campaign, rotate compromised credentials and reverify recovery | distributed attempts and generic response equivalence |
| **Session theft** — Stolen cookie/token or stale revoked session | HttpOnly/Secure host-only cookies, short lifetime, rotation, CSRF, no localStorage tokens, server revocation | New-session anomalies, privileged step-up failures | Revoke family/security epoch, rotate affected secrets | logout/revocation and stolen session without step-up |
| **Privilege escalation** — Role/admin self-grant or mass-assigned approval fields | Central default-deny policies, delegation ceiling, DTO allowlists, maker/checker | Role/permission/support grant audit | Revoke grant, invalidate sessions, review affected actions | multi-role deny and self-approval using second role |
| **Tenant escape** — Forge context or pool reuse to access tenant B | Trusted tenant resolution, FORCE RLS, composite FKs, non-owner runtime role, per-context transactions | Tenant-denial telemetry, RLS regression canaries | Suspend affected credential/path, isolate deployment, audit scope and notify per reviewed incident process | two-tenant reads/writes, FK, pool rollback, worker/cache/export/AI |
| **IDOR/BOLA** — Known UUID gives object or nested child access | Object/subject/scope checks before field fetch, list/count filtering, uniform missing response | Repeated object probes/denials | Revoke abused access and investigate exposure | parent-child mismatch, principal request UUID and graph path |
| **SQL injection** — Caller filter or report creates arbitrary SQL | Parameterized typed SQL, allowlisted query templates, no raw SQL tools, least DB privileges | SAST/DAST, database query anomaly | Disable vulnerable operation, rotate DB credential, patch and scope incident | filter/sort/cursor injection and policy-setting attempt |
| **XSS** — Notice, evidence preview or theme injects script | Structured sanitized content, output encoding, strict CSP, no arbitrary HTML/theme script, separate download origin | CSP reports and scanner/UI tests | Withdraw malicious content, invalidate sessions if exposure, patch rendering | stored/reflected payloads in every rich text/display field |
| **CSRF** — Browser cookie triggers authorized mutation | Origin validation, CSRF token, SameSite cookies, no GET mutation | CSRF rejection metrics | Revoke impacted session, reverse reversible changes with audit | cross-origin form/fetch, missing token, unsafe GET |
| **SSRF** — Connector/source import follows private or metadata endpoint | Egress proxy, allowlist, DNS/IP validation each hop, redirect limits, approved private route exceptions | Egress denials and metadata endpoint alerts | Disable connector, rotate exposed workload secrets | DNS rebinding, IPv6/private IP and redirect chain |
| **Unsafe uploads** — Executable/polyglot/zip bomb bypasses declared MIME | Magic-byte/type/size validation, no archives initially, immutable quarantine and sandbox scanner | Scan/limit alerts and checksum mismatch | Quarantine/revoke exact versions, purge previews, rescan | spoofed MIME, malformed PDF, expansion bomb, replacement race |
| **Malicious evidence files** — Document exploits preview/scanner or contaminates evidence | No active content, isolated preview origin/runtime, accepted-scan gate, checksum/provenance | Scanner crashes, abnormal child/network activity | Isolate scanner pool, revoke evidence/derived files and rebuild | malicious document corpus and scanner outage fail-closed |
| **Secrets leakage** — Logs/build/model/history expose connector/key material | Secret references, workload identity, redact logging, secret scans, no PII in Temporal | Gitleaks/DLP and key access anomalies | Rotate/revoke keys, purge disclosed logs under incident policy | canary secret through error/log/prompt paths |
| **Supply-chain compromise** — Dependency/CI/plugin update introduces code execution | Pinned lockfile/images, signed artefacts/SBOM, SCA, protected reviews, sandbox adapters | Signature/provenance verification and dependency alerts | Rollback safe signed build, revoke signing/workload keys, rebuild trusted pipeline | tampered image/package and unsigned connector rejection |
| **Backup compromise** — Stolen backup and keys reveal all tenants | Separate credential plane, encryption/KMS separation, immutability/residency | Backup access and key unwrap audit | Revoke keys where feasible, scoped incident investigation and restore trusted copy | unauthorized restore/decrypt and key-loss drill |
| **Ransomware** — Runtime compromise encrypts data/deletes backups | Least privilege, immutable backups, restricted storage delete, signed runtime | Mass update/delete anomalies, backup health | Isolate, restore clean environment, replay erasure ledger and reconcile jobs | restore drill with unavailable primary |
| **Malicious insiders** — Operator browses evidence or rewrites audit | No default tenant access, dual support approval, WORM anchors, separation of duties | Privileged session/download audit and anchor verification | Revoke privileged identity, independent investigation, recover anchors | platform operator denied tenant content and chain-tamper detection |
| **Compromised service account** — Adapter token escalates to broad API access | One-tenant narrow capability, short expiry, network isolation, no interactive role inheritance | Token use/capability anomaly and rate metrics | Revoke service credential, halt pending work and reconcile effects | wrong audience/tenant/capability and revoked retry |
| **API abuse** — Expensive graph/search/export or hot consent floods | Limits/quotas/pagination/deadlines, bounded hops, async jobs, concurrency controls | Latency/cost/quota and unusual query patterns | Throttle tenant/client, cancel work safely, scale under limits | large fanout, duplicate idempotency, tenant fairness load |
| **Webhook attacks** — Forged/replayed events trigger cross-tenant actions | Registered endpoint identity, signature/time window, dedupe, schema and egress validation | Replay/signature failures and backlog | Rotate secret, disable subscription, reconcile accepted event IDs | forged tenant in signed payload, old timestamp, duplicate delivery |
| **Connector compromise** — Malicious remote result/adapter abuses secrets or deletion | Sandbox signed adapters, response schema, capability scoping, read-only default, target approvals | Egress/run/proof anomalies | Revoke credentials, isolate runner, mark unknown effects for reconciliation | forged response target, capability escalation, ambiguous delete retry |
| **AI prompt injection** — User instructs model to override policies or expose prompts | Deterministic auth outside model, no secret prompts, typed tool allowlist | Tool denial/security evaluation suite | Disable run/tool/provider, review auditable proposals | direct jailbreak, SQL/shell/secret requests |
| **Indirect prompt injection** — Retrieved file/webhook embeds hostile instructions | Untrusted-source labeling, minimal context, tool outputs treated as data, no authority from text | Adversarial corpus tests, unexpected tool proposals | Quarantine source/chunks, cancel runs and rebuild index | embedded document instructions and poisoned evidence |
| **AI data exfiltration** — Model sends context to external tool/URL or provider | Approved provider/data modes, redaction, egress allowlist, no arbitrary URL tool, output DLP | Egress/DLP and retrieval provenance | Disable provider, revoke exposed credentials, incident review | encoded exfiltration and disallowed provider route |
| **AI privilege escalation** — Model forges approval or acts as administrator | Original actor reauthorization, digest-bound human approvals, no model-issued grants | Policy decision/tool audit | Revoke proposal, halt tool work and reconcile effects | forged approval, changed arguments after consent, stale role |
| **Cross-tenant AI retrieval** — Vector/cache returns tenant B content | Tenant/scope filter before retrieval, RLS, auth per result, scoped cache, revocation purge | Synthetic sentinel leakage tests and retrieval audit | Disable retrieval, purge faulty index/cache, rebuild scoped projection | nearest-neighbour cross-tenant sentinel and revoked document |
| **Unsafe AI tool execution** — Model deletes, rejects rights or submits breach notice | Dangerous tools unavailable by default, human gates, typed domain services, no DB/shell | Tool invocation and approval mismatch alerts | Cancel before effect; reconcile/restore reversible work; incident for irreversible action | delete/legal rejection/regulator send tool attempts |
| **Regulatory poisoning** — Unverified document becomes authoritative law | Official-source provenance, immutable digest, maker/checker legal review, signed bundles | Corpus traceability and source-diff review | Withdraw publication by superseding reviewed version, impact review | tampered manifest, missing source, illustrative control publication |
| **Deletion/hold race** — Concurrent hold or stale approval permits destructive effect | Plan-version approval, target leases, live hold check, bounded execution, reconciliation | Hold/deletion conflict audit and unknown target alerts | Stop remaining targets, investigate completed effect; cannot promise undo | hold created before execute, plan changed after approve |
| **Audit loss/tampering** — Business change commits with no durable audit or history rewritten | Same transaction, insert-only role, sequence chain and external signed anchors | Outbox/audit reconciliation, anchor age and chain verification | Stop affected mutations, preserve evidence, restore trusted chain | audit write failure rollback and privileged history rewrite |

## Ownership, evidence and residual risks

Identity/Authorization owns authentication/session/privilege tests; Tenancy owns cross-surface isolation; platform security owns injection, supply-chain, secrets and runtime; Evidence owns upload/custody; Integrations owns egress/webhooks; AI owns model/retrieval/tool tests; Regulatory owns legal provenance; lifecycle owner owns deletion/hold races; operations owns backup/DR; Audit owns durability/integrity. A release threat register attaches test IDs/results, reviewer, residual likelihood/impact, accepted exceptions and expiry to each row. No row is closed by merely implementing a checkbox.

RLS does not contain arbitrary code execution with application credentials; dedicated profiles reduce blast radius. Key compromise may make retained ciphertext readable; rotation alone cannot undo disclosure. Hash chains without independent anchors do not prevent privileged history rewriting. Prompt injection cannot be assumed solved by prompts or a detector; tool/data containment is the security boundary. External deletion and regulator delivery may be irreversible; uncertain outcomes require reconciliation. These residual risks are explicit review items.

Testing occurs only against authorized local/staging environments with synthetic data. Production penetration activity needs separately approved scope. Independent VA/PT, API review, tenant escape exercise, configuration/source/container review and remediation verification are required before government production. The bid milestone does not waive tests for any included feature.
